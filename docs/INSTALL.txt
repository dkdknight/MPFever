MPFever 0.3.4-experimental - Installation and first game
========================================================

REQUIREMENTS (every player)
---------------------------
- Windows 10 or 11 with .NET Framework 4.8 (already included in Windows 10/11).
- Transport Fever 3 on Steam, up to date. Every player must have the same game version
  and the same mods.
- Steam running.


1. INSTALLATION (every player)
------------------------------
1. Close Transport Fever 3.
2. Extract the archive anywhere, for example to your Desktop. Keep the folder structure:
       MPFever\
         MPFever.exe
         winhttp.dll
         mod\mpfever_1\...
         (documentation files)
3. Start MPFever.exe. At start it finds the game through Steam, installs the mod and
   enables it for new games. The log window shows "Mod installed in ...".
   - If Windows SmartScreen says "Windows protected your PC": click "More info", then
     "Run anyway".
   - MPFever also copies winhttp.dll into the game folder (see "What MPFever changes on
     your PC" in README.txt).

Always start Transport Fever 3 THROUGH MPFever.exe when you want to play together
(MPFever.exe starts the game itself). Started normally from Steam, the game is a normal
solo game: the mod does nothing.


2. THE SAVEGAME (host)
----------------------
The host plays any of their own savegames, even one created without MPFever: the
mod is added to it automatically when it is loaded for a multiplayer game. The other
players receive the host's game automatically when they join (no file to send).


3. NETWORK (host)
-----------------
The other players connect to the host on TCP port 28090.

Choose one:
a) Port forwarding: on the host's internet box/router, forward TCP port 28090 to the
   host's PC, and allow MPFever.exe in the Windows firewall (Windows asks the first
   time you host: tick "Private" and "Public" networks). Needed for Steam invitations.
b) Virtual LAN: every player installs the same tool, for example Radmin VPN, ZeroTier
   or Tailscale, and joins the same network. The host gives the IP address shown by
   that tool; the others join by IP.
c) Same local network: use the host's local address (for example 192.168.1.20).


4. PLAY
-------
Everybody: start MPFever.exe. Transport Fever 3 starts by itself (the MPFever window
stays minimized). In the game's main menu, click "Multiplayer (MPFever)" (under the
cards) and type your player name.

Host:
1. "Host a game", click the savegame to share, then "Host".
2. The savegame loads and the game starts. Your friends can now join.
3. Invite friends: click "Invite Steam friends" in the MPFever window of the main menu
   (or friends right-click you in their Steam friends list, "Join game").

Other players, either:
- accept the host's Steam invitation (Transport Fever 3 and MPFever start by
  themselves if needed), or
- "Join a game", type the host's address (for example 89.12.34.56 or
  89.12.34.56:28090), then "Join".
The host's game is sent to you (progress shown in the MPFever window) and loads by
itself. Each time a player joins, every game pauses and reloads the host's game for a
few seconds, then everybody continues together.

During the game:
- Play normally. Anybody can build, buy vehicles, create lines...
- Speed and pause: use the game's own speed buttons (they ask the host). Every game
  always runs at the same speed.
- If the games differ, MPFever corrects it: money at once; anything else with an
  automatic resynchronisation (pause, everybody reloads the host's game, about 20
  seconds, then the game resumes by itself). Do not touch anything while it loads.
- To stop: the host saves the game (normal save), then everybody quits. Closing the
  game also closes MPFever.

Developer mode (MPFever.exe --dev) keeps the old window with the Host / Join buttons
and the local test.


TROUBLESHOOTING
---------------
- "Transport Fever 3 not found": Steam must be installed normally and the game
  installed in one of its libraries.
- "Cannot connect": check the address, the port, the host's firewall / port
  forwarding, or use a virtual LAN.
- No "Multiplayer (MPFever)" button in the main menu: the game was not started by
  MPFever.exe, or another winhttp.dll is in the game folder (see the MPFever log).
- The game shows "press any key" after a resynchronisation and does not continue: press
  a key, and please report it (with the logs, see README.txt).
- Something does not appear in the other game: please report it with the logs.
