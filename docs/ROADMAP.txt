MPFever - Roadmap
=================

The order may change with your feedback. Versions are not dated: each one comes when
it is stable enough.

0.1 - Experimental co-op
  [x] Cooperative play in one shared company, connection by IP address
  [x] Synchronised construction tools: roads, tracks, joins, upgrades, stops (also on
      tram tracks), stations, depots, buildings, bulldozer
  [x] Synchronised vehicles purchases, lines, assignments, game speed and pause
  [x] Host authority: periodic state comparison, automatic money correction,
      automatic resynchronisation from the host's savegame
  [x] Built into the game: no extra button in the game interface

0.2 - Stability and easier start
  [x] Automatic transfer of the host's savegame when joining (0.2.0)
  [x] Start from any savegame, mod added automatically (0.2.1)
  [x] Fix the slow simulation drift without limiting the processor (0.1.1)
  [x] Reconnect after a lost connection (0.2.1)
  [x] Main cause of desyncs found and fixed: the game's Lua walked its tables in a different
      order on every PC (0.3.4, see RESEARCH.md)
  [x] Players on different Windows compute alike: Windows' mathematical
      functions give other last digits from one Windows build to the other; every game now
      computes them with MPFever's own (0.5.1)
  [x] Players whose games are in different languages: the host's names for new stations, lines and vehicles (0.5.14)
  [x] Vehicles queuing on a road kept in the same order on every game (0.5.14)
  [x] One-way road upgrades rebuilt the same way round on every game; an incomplete install (MPFever.exe copied
      alone) told plainly instead of reloading every two minutes (0.6.5)
  [ ] Games that number new objects differently without any action (3-player sessions, #109): diagnostic build
      with the players, cause still searched
  [ ] Tests and fixes for 3 to 8 players
  [ ] Feedback from the first testers

0.3 - Playing with friends
  [x] Steam invites (join through your Steam friends list) (0.2.0)
  [x] Join a session that is already running (0.2.0)
  [x] Player list and sync state inside the game, from the pause menu (0.3.4)
  [x] Chat inside the game interface (0.3.5)
  [x] Permissions and budgets per player, plans and notes for the team (game options, 0.6.0)
  [x] Game rules chosen by the host and kept in the savegame: start money, sharing rules on or off, bankruptcy (0.5.14)
  [x] Signals on the map ("Here", "Watch out", "Build here") seen by every player (0.5.14)
  [x] Players' journal, "built by", see a player's view (game options, 0.6.0)
  [x] Public games: ban list, approval of arrivals, friends only, players at most (game options, 0.6.0)
  [x] Personal mods (interface only) that every player may have or not, missing mods installed from the game's Mod Hub,
      the host's local mods sent from its PC (0.5.0)
  [x] What the others are building shown on the ground before their click (0.5.0)

0.4 - Separate companies
  [x] Each player runs their own company on the same map, chosen by the host (0.3.0)
  [x] Own money, vehicles, lines and stations per company, a colour per company, the company
      is found again after a reconnection (0.3.0)
  [x] Loans for every company (0.3.2)
  [x] Contracts for every company, owner shown in the windows, company tied to the Steam account (0.3.3)
  [x] Company-window actions for every company, money transfers, colour picked in the lobby,
      a table of the companies (0.4.4)
  [x] Bankruptcy: the company's empire auctioned to the other companies, the player starts again (0.5.0)
  [x] Shared stations' fees in the finances (0.5.0)
  [x] Competition on cargo and passengers: market shares, alerts (game option, 0.6.0)
  [x] Ranking, game goal, yearly report; tenders; territories and handicaps; trade between companies; stock market
      (game options, 0.6.0)
  [x] Each company's own rank, never the host's notification on another player's game (0.6.3 to 0.6.5)
  [ ] The game's achievements counted per company (#95)

0.5 - Mixed modes
  [x] Shared companies and separate companies in the same game (0.5.0)
  [x] Joining, leaving and merging companies (0.5.0)
  [x] Shared stations with a fee per stop (0.3.3)
  [x] Rules for shared tracks and depots: private, open, or a toll per passage (0.5.0)

0.6 - Computer companies (experimental since 0.5.12; 1.0 once they are complete and reliable)
  [x] Computer companies added and coloured by the host in its lobby, kept in the savegame (0.5.12)
  [x] Bus lines in and between towns, purchases, given up lines, bankruptcy like a player (0.5.12)
  [x] Freight by truck between industries and to the towns, rounds (0.5.13)
  [ ] Streets to the industries no truck reaches (tried since 0.5.13, refused by the game so far: they need a real route)
  [x] A level for each one (Easy, Normal, Hard), and what they do shown to every player (0.5.13)
  [x] They stay solvent and grow: vehicles fitted to what each line earns, careful growth, lines between towns first,
      one cheap loan at a time, their own start money (0.5.14)
  [x] Never bankrupt; a floor of money; freight that pays off in the long run (an industry grows when its cargo is
      carried) (0.6.0)
  [x] Deliveries of goods to the towns (0.6.2)
  [x] Railways: two stations, the track (round the towns, bridges over roads, tracks and rivers), a depot, a line and
      trains; a train more where cargo piles up, the trains of a losing line sold (0.6.4, experimental)
  [ ] Signals, electric trains and warehouses
  [ ] Ships and planes
  [ ] Computer companies on a dedicated server

Later - Persistent worlds
  [x] Dedicated server running the world without the host's PC (0.3.12: MPFever.exe --server, separate archive,
      see SERVER.txt; to be tested in long real games; 0.5.8: start buttons, without display)
  [ ] Persistent world that players join and leave at any time
  [ ] Larger player counts (MMO-like)
